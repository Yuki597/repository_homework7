# Блокова модель і просте позиціювання

## Мета проєкту

Навчальна сторінка для демонстрації роботи box-sizing: border-box, комбінацій padding, border та margin, абсолютного позиціювання позначки всередині відносно позиціонованої картки та контролю переповнення вмісту.

## Використані властивості та підходи

- Глобальний ресет _::before, _::after
- Різні комбінації padding, border і margin для двох карток
- Позиційована позначка (position: relative на картці та position: absolute на позначці) із зарезервованим верхнім відступом
- Обмеження ширини, центрування через margin: 24px auto та контроль переповнення через overflow.

## Перевірка у DevTools

Розміри двох карток і позиціювання позначки перевірено в DevTools. На вузькій ширині позначка не перекриває заголовок, а горизонтальний скрол сторінки відсутній.
